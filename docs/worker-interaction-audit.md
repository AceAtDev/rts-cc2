# Small worker interaction differences

Audit date: 2026-10-09. These findings compare current prototype code with fresh primary guide reads and the pinned extracted catalog. Confidence is stated separately from native behavior that still needs measurement.

| Priority | Detail | Evidence and next step |
| --- | --- | --- |
| P1, direct arithmetic failure | Repair charges its nominal tick before clamping final restored HP | [Repair effect](https://github.com/Talv/sc2-data/blob/1921f856b0443d4cbd366c472cd7984fa6a224d1/mods/liberty.sc2mod/base.sc2data/GameData/EffectData.xml) specifies `.25` resource factors. Integrate `quoteRepair` for affordability, payment and restoration; see [repair costs](repair-cost-fidelity.md). Native fractional rounding remains unverified. |
| P1, documented control/catalog mismatch | CC Load instantly hides nearby SCVs using a 130-world-unit search; Load/Unload ignore Shift | [Liberty CommandCenterTransport](https://github.com/Talv/sc2-data/blob/1921f856b0443d4cbd366c472cd7984fa6a224d1/mods/liberty.sc2mod/base.sc2data/GameData/AbilData.xml) sets search radius 8; [Core transport](https://github.com/Talv/sc2-data/blob/1921f856b0443d4cbd366c472cd7984fa6a224d1/mods/core.sc2mod/base.sc2data/GameData/AbilData.xml) sets range 1. Blizzard [Special Control](https://news.blizzard.com/en-us/article/4552955/game-guide-special-control) expressly lists queueable Load/Unload. Capture approach, contact, reservation and queue execution before implementing transport geometry. |
| P1, documented missing movement | Construction SCVs remain at one exterior contact position with ordinary collision | [TerranBuild](https://github.com/Talv/sc2-data/blob/1921f856b0443d4cbd366c472cd7984fa6a224d1/mods/liberty.sc2mod/base.sc2data/GameData/AbilData.xml) uses Construction mover and PeonDisableCollision. [5.0.14 notes](https://news.blizzard.com/en-us/article/24162754/starcraft-ii-5-0-14-patch-notes) specify relocation delays of 4.64–6.07 real seconds. Native construction contact trajectories remain unmeasured. |
| P2, concrete asymmetry requiring native validation | Gas queues promote Move after deposit, and explicit Gather/Smart gas reissues both reset progress | [Gas resource behavior](https://github.com/Talv/sc2-data/blob/1921f856b0443d4cbd366c472cd7984fa6a224d1/mods/liberty.sc2mod/base.sc2data/GameData/BehaviorData.xml) has extraction time 1.981 and no mineral return delay. Capture gas Gather→Shift Move and repeated explicit Gather versus Smart; mineral measurements cannot certify gas transitions. |
| P2, concrete demo behavior requiring native validation | Repair autocast treats Hold's null order as idle and can chase a repair target | [Basic Unit Controls](https://news.blizzard.com/en-us/article/4552956/game-guide-basic-unit-controls) confirms repair autocast during Patrol. It does not establish Hold, Move or resource-starvation policy. Capture those contexts before changing acquisition or continuation. |

Existing explicit mineral Gather versus Smart, cargo-wait deferral, no-home cargo continuation and destroyed-field recovery already have native measurements; see [worker recovery](worker-recovery.md). Started-building cancellation currently uses the pinned `.75` refund factor. Queued placement payment moments, shared planned-building handoff and cancellation recovery still need native comparison rather than an inferred change to resource payment.

The catalog snapshot is historical. Current patch notes and that older catalog cannot establish every current-client timing or trajectory. No licensed raw traces, maps or native assets are included here.
