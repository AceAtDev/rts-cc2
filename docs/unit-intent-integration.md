# Unit intent and pursuit integration

The preceding gameplay pass established the documented Faster clock and several control operations. It did not establish native unit intelligence. This pass fixes reproduced problems in command execution rather than strengthening opponent strategy.

## Corrected behavior

- Attack Move's arrival reservation and march corridor no longer substitute for an enemy pursuit destination. A 24-SCV browser squad now closes and damages its encountered target while retaining its original march destination.
- Blocked pursuit finishes a budgeted search against a stable target snapshot. Target motion no longer repeatedly cancels an unfinished frontier. Existing usable corridors continue while a replacement is planned; a clear final leg follows the current target. Direct pursuit remains responsive to current coordinates.
- Explicit Gather retains the clicked mineral unit on acceptance, queued activation, and saved Return resumption. Local automatic reassignment occurs after encountering an occupied field or depletion, rather than silently changing the player's target before travel. Empty queued Return completes without travel, payment, or a phantom trip.
- The pinned native Move tooltip says to move to an area or follow a target unit without engaging enemies. M-clicking a friendly or visible enemy unit now issues Follow; M-clicking ground still issues Move. Following an enemy snapshots its observed position. Fog does not expose live coordinates or instantly reveal an unseen death; reaching the last observed follow point promotes the next command. Follow offset and fog completion remain prototype policies.
- Explicit Attack records its visible target at acceptance, including when it vanishes before the first gameplay loop. A last-seen fallback preserves the queue and acknowledgement metadata, omits a live hidden-target waypoint pointer, and moves in the same update. Reappearance restores explicit preference. Visible target death completes the manual attack; it does not invent a new objective.
- Automatic acquisition and pursuit retention use separate boundaries, avoiding scan-edge oscillation. Initial equal-priority candidates use footprint distance; an established equal-priority target stays stable. The visible pursuit bound remains custom.
- Queued Patrol records its return origin when activated after earlier waypoints, rather than returning to where the unit was when the queue was issued. Existing patrol endpoints survive temporary combat and automatic repair. A native queued Move→Patrol capture now confirms the activation origin in the historical 4.10 client.

- Native worker captures replace the combined harvest lock with 45-loop extraction followed by an eight-loop cargo wait. The field becomes available immediately; queued Move starts carrying cargo before any deposit, and Move/Stop/Hold defer until departure. Deposit can resume the outward leg in the same loop.
- Aligned cold-start attacks now hit on the measured Marine loop 2 and SCV loop 4. Newly created positive windups wait until the following loop to process elapsed time; movement cancels windup while preserving cooldown.
- Unreserved point Move reaches its exact endpoint with SCV forward braking, and Tanks align their bodies before translating at the measured stationary turn rate.

- Compact Move and Attack Move now preserve mean-centered formation offsets within the measured radius-inclusive six-game-unit extent. Same-batch start snapshots avoid false repulsion from sequential updates; wide, overlapping or projected layouts retain a custom packed fallback. Loose compact packs complete at exact assigned centers, while contact packs retain a settling tolerance.

Sources and narrower limits are in [worker intent](worker-intent-followup.md), [combat orders](unit-order-fidelity.md), and [pursuit movement](movement-pursuit-fidelity.md). Existing speed, acceleration and weapon values remain unchanged; Tank now also imports its previously omitted TurnBeforeMove flag and inherited stationary turning rate. The later native arrival pass changes point completion and SCV braking from direct native measurements; see [arrival comparison](native-arrival-fidelity.md).

## Verification

The integrated pass verifies 370 browser checks across twenty suites and 275 isolated checks. A serial 120-unit/600-step simulation stress averages 3.022 ms, P95 5.6 ms, worst 33.2 ms, commands 1.2–4.1 ms, with no invalid positions. These measure custom simulation work rather than native or rendered-input parity.

`tests/unit_intent_integration.py` passes 23 browser checks using the real game executor at 22.4 Hz, including actual M-click targeting, visible moving Follow, fog and unseen death, queued Hold, same-loop attack fallback, original-target restoration, hidden explicit-target death, queued Patrol, formation-isolated combat, and all six implemented units attacking with preserved successors. The updated worker suite checks both exact input acceptance and later busy-field redistribution, retaining every-worker trip and exclusive-harvester assertions.

The isolated suites add 12 worker-intent checks, 20 combat-order checks and seven real-navigation pursuit checks. In the constrained moving-target fixture, the previous solver moved on zero of 200 updates; the corrected solver moves on 173, completes routes, respects the 16-node-per-update budget, and has no cancellations caused by target motion. That comparison is between prototype versions, not between this solver and native SC2.

The user accepted the research license and incorporated EULA before installation. Native captures identify game 4.10.0.75689, base/data build 75689, a map hash and seed; ten isolated Move trajectories using the captured initial headings now match both positions and completion loops. Native Gather/Smart retain the requested mineral tag, Move-to-unit follows, and queued Patrol returns to its activation origin. The additional browser suites verify 19 worker phase, eight attack phase, four Tank turn and nine compact formation checks. Compact native goal probes match within fixed-point mean quantization, and the loose 24-Marine formation matches final centers and completion loop 98, with a measured 0.01419-GU diagonal transit difference. Native assets and raw generated data remain outside the public project. Crowd navigation, acquisition timing and human-input comparison remain necessary; camera, animation, selection and frame pacing independently affect perceived smoothness.
